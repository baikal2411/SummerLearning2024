### 中位值滤波法

![image-20240725221510875](D:\desktop\暑假计划\匠人手记\image-20240725221510875.png)

```c
unsigned char MiddleValueFilter(void)
{
    unsigned char i,j,k;
    unsigned char Temp;
    unsigned char ArrDataBuffer[N];
    //一次采集N组数据放在buffer当中
    for(i=0;i<N;i++)
    {
        ArrDataBuffer[i] = GetAD();
        Delay();
	}
    for(j=0;j<N-1;j++)
    {
        for(k=0;k<N-j;k++)
        {
            if(ArrDataBuffer[k]>ArrDataBuffer[k+1])
            {
                Temp=ArrDataBuffer[k];
                ArrDataBuffer[k]=ArrDataBuffer[k+1];
                ArrDataBuffer[k+1]=Temp;
            }
        }
    }
    return ArrDataBuffer[(N-1)/2];
}
//采集信息后进行冒泡排序，选择出中位数进行返回
```

### **消抖滤波法**

设置一个滤波计数器，将每一个采样值与当前有效值相比较，采样值与有效值相等则计数器清零，若不等则计数器加一，若超过上限则使用本次值替换当前有效值并且清计数器。
